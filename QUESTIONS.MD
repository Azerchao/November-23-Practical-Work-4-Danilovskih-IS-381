# Контрольные вопросы

**1. Чем класс отличается от объекта?**
Класс — шаблон (чертёж): описывает свойства и методы. Объект — конкретный экземпляр, созданный по этому шаблону оператором `new`; у каждого объекта свои значения свойств.

**2. Для чего нужен конструктор и когда он вызывается?**
`__construct()` задаёт начальное состояние объекта (присваивает свойства, проверяет аргументы). Вызывается автоматически один раз в момент `new Класс(...)`.

**3. Что означает `$this` и почему он недоступен в статических методах?**
`$this` — ссылка на текущий объект внутри его методов. Статический метод принадлежит классу и вызывается без объекта (`Класс::метод()`), поэтому «текущего объекта» нет.

**4. Чем отличается `$obj2 = $obj1` от `$obj2 = clone $obj1`?**
При присваивании обе переменные указывают на один и тот же объект (изменение через одну видно в другой). `clone` создаёт новый независимый объект с копией значений свойств (поверхностная копия; вложенные объекты остаются общими, если не переопределён `__clone`).

**5. Чем статическое свойство отличается от обычного? Как к нему обратиться?**
Статическое принадлежит классу и общее для всех объектов; обычное — у каждого объекта своё. Обращение: `Класс::$prop`, внутри класса — `self::$prop` (или `static::$prop`).

**6. Что такое readonly-свойство и когда его можно присвоить?**
Свойство (PHP 8.1), которое можно инициализировать только один раз и только из области видимости класса (обычно в конструкторе). Повторная запись вызывает `Error: Cannot modify readonly property`. Должно иметь тип.

**7. Что такое продвижение свойств в конструкторе?**
Запись модификатора доступа перед параметром конструктора (`__construct(private string $name)`): PHP сам объявляет свойство и присваивает ему значение — без отдельного объявления и `$this->name = $name`.

**8. Как реализовать цепочку вызовов методов?**
Каждый метод в конце делает `return $this;` и объявляет тип возврата `static` (или `self`): `$qb->select()->where()->limit()`.

**9. Назовите три магических метода и случаи, когда PHP их вызывает.**
- `__toString()` — при приведении объекта к строке (`echo $obj`);
- `__set($name, $value)` — при записи в недоступное или несуществующее свойство;
- `__call($name, $args)` — при вызове недоступного или несуществующего метода.
(Также: `__construct` — при создании, `__get` — при чтении недоступного свойства, `__destruct` — при уничтожении объекта.)

**10. Чем `protected` отличается от `private` при наследовании?**
`protected` доступен в самом классе и в наследниках; `private` — только в классе, где объявлен (наследник его не видит). Снаружи недоступны оба.

**11. Что делает ключевое слово `final`?**
Для метода — запрещает его переопределять в наследниках; для класса — запрещает от него наследоваться.

**12. Как работает `spl_autoload_register`?**
Регистрирует функцию-загрузчик. Когда PHP встречает неизвестный класс (`new`, `::`, `extends`, type-hint с `instanceof` и т. п.), он по очереди вызывает зарегистрированные загрузчики, передавая полное имя класса; загрузчик находит файл и подключает его через `require`.

**13. Как стандарт PSR-4 связывает пространство имён и путь к файлу?**
Префикс пространства имён сопоставляется базовой папке, остаток имени — подпапкам, имя класса — имени файла: при `App\` → `src/` класс `App\Models\User` лежит в `src/Models/User.php`.

**14. Когда нужно выполнять `composer dump-autoload`?**
После создания/изменения секции `autoload` в `composer.json` (например, смены префикса или папки) и при добавлении новых папок/классов, которые ещё не попали в карту автозагрузки (для PSR-4 новые файлы в уже зарегистрированной папке подхватываются сами, но для classmap и оптимизированного автозагрузчика — нужна перегенерация).
